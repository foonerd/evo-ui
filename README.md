# evo-ui

Public release repository for the `evo` next-generation UI layer.

## Purpose

`evo-ui` is the curated public release stream for showcase-ready UI work.

It contains promoted, release-quality UI deliverables aligned with:

- `evo-core` runtime contracts
- device plugin contracts
- gateway/API contract discipline

## Position in the repo model

- `evo-ui-eng`: private engineering/prototyping stream
- `evo-ui` (this repo): public release stream

Changes are promoted from engineering only after contract, risk, and quality gates are satisfied.

## Scope

- Deliver the complete, intuitive, appealing human layer for the evo showcase device.
- Preserve strict separation between runtime semantics and presentation/theming.
- Stay vendor-neutral at framework/reference-device level.
